# DimmLab

**世界の見え方に、新しい次元を。**

数学を思考の基盤として、身近な疑問を予想・実験・応用しながら洞察力を鍛えるWebアプリです。

## MVP v0.1

- 割合の錯覚：値上げ・値下げの基準を操作
- 確率の錯覚：公平なコイン投げシミュレーターと累積割合
- 増え方の錯覚：指数成長の倍率と日数を操作
- 共通フロー：**予想 → 実験 → 別場面への転用 → 発見の記録**
- 発見ノート：ブラウザの `localStorage` に保存（アカウント・サーバー不要）
- スマホ対応の日本語UI

## ローカルで実行

Node.js 18+ を使用します。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

```bash
npm run build
npm run preview
```

## 技術

React 18 / TypeScript / Vite 5 / CSS / SVG。初期段階では外部API、分析SDK、認証、課金は使用しません。

## 教育上の前提

- **シミュレーションは数学的な証明ではありません。**
- 直感的な誤答を罰せず、条件を操作して結果を観察できるようにしています。
- 自由記述はブラウザ内でのみ保存されます。履歴を消去すると復元できません。
- 発見ノートの記録数は学習効果を保証するものではありません。理解の評価には未見の応用問題を利用します。

## 開発予定

- 発見ノートのエクスポート
